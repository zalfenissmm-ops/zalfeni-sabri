# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## Peaks & Troughs Chart — peaks_troughs_chart.py

أداة ثالثة تحدد القمم والقيعان بطريقة فراكتال (نافذة N شمعة) مع تأخير التأكيد،
قاعدة الإلغاء، الزجزاج، الرينج الرئيسي وكسره، وتحديد الترند — وترسمها مباشرة
على شارط شموع (ملف HTML واحد يحتوي SVG، بدون أي مكتبة خارجية).

القواعد المطبّقة بالترتيب:

1. اختيار N (3، 5، أو 7 شموع فردية) = حجم النافذة.
2. الشمعة الوسطى فالنافذة هي المرشحة (قمة = أعلى high، قاع = أدنى low فالنافذة).
3. التأكيد يتأخر (N-1)/2 شمعة بعد الشمعة الوسطى.
4. قاعدة الإلغاء: نفس النوع مرتين وراء بعضهم بلا نقطة معاكسة بينهم → ياخذ الأقوى، يلغي الباقي.
5. الزجزاج: يربط كل نقطة مؤكدة بالي قبلها، يتناوب قمة/قاع/قمة/قاع.
6. الرينج الرئيسي: آخر نقطتين متتاليتين فالزجزاج → حدين أفقيين ثابتين.
7. أي حركة داخل الرينج = فرعية (ما تدخلش الخط الرئيسي، تصلح لفيبو/دايفرجنس/نماذج).
8. كسر الرينج = نقطة رئيسية جديدة (فوق = استمرار الترند، تحت = انعكاس محتمل) → رينج جديد من النقطة الجديدة + الي قبلها.
9. الترند: HH+HL رئيسية متتالية = صاعد | LH+LL رئيسية متتالية = هابط.

### الاستخدام

```bash
python3 peaks_troughs_chart.py data.csv --window 5 --out chart.html
```

- `--window`: حجم نافذة الفراكتال N، لازم تكون 3 أو 5 أو 7 (default: 5).
- `--last`: تقتصر التحليل على آخر N شمعة من الملف (اختياري).
- `--out`: مسار ملف HTML للرسم الناتج (default: `peaks_troughs_chart.html`).

يفتح ملف الـ HTML الناتج مباشرة فأي متصفح، ويعرض شموع OHLC + خط الزجزاج
الفرعي (منقّط) + الخط الرئيسي (سميك، معلّم بـ HH/HL/LH/LL) + مربعات الرينج
التاريخية + الرينج النشط الحالي (مظلل ومحدد بالأزرق).

### مثال على المخرجات

```
Window (N)             : 5  (confirmation lag = 2 candle(s) after the middle bar)
Confirmed swing points  : 33  (after cancellation rule)
Main structure points   : 15
Active main range       : upper=86.57600 (candle #115, 2024-01-116)
                          lower=80.44880 (candle #109, 2024-01-110)
Trend                   : downtrend
Chart written to        : chart.html
```

## MT5 Indicator — PeaksTroughsChart.mq5

نفس القواعد التسع (بالضبط) لكن كمؤشر MetaTrader 5 يرسم مباشرة على شارط MT5 نفسه —
بدون توليد أي ملف خارجي، ويشتغل لايف على أي سيمبول/فريم.

### التركيب

1. افتح **File → Open Data Folder** فـ MT5، وادخل مجلد `MQL5/Indicators`.
2. انسخ `PeaksTroughsChart.mq5` لهاذاك المجلد.
3. افتح **MetaEditor** (F4 من MT5)، افتح الملف، ثم **Compile** (F7).
4. رجّع لـ MT5، اسحب المؤشر من **Navigator → Indicators** على الشارط.

### الإعدادات (Inputs)

- `InpWindow`: نافذة الفراكتال N — لازم 3 أو 5 أو 7 (default: 5).
- `InpLookbackBars`: عدد الشموع المحلّلة للخلف (default: 400).
- `InpShowSecondaryZigzag`: إظهار الزجزاج الفرعي (منقّط، رمادي).
- `InpShowHistoricalRanges` / `InpMaxHistoricalRanges`: إظهار مربعات الرينج القديمة وعددها.
- `InpFutureExtensionBars`: كم شمعة يمتد الرينج النشط لليمين (للعرض فقط).
- ألوان الخط الرئيسي، الزجزاج الفرعي، الرينج النشط، والرينج القديم قابلة للتخصيص.

المؤشر يرسم القمم/القيعان الفرعية (نقاط مجوّفة صغيرة + خط منقّط)، الهيكل الرئيسي
(خط سميك ملوّن معلّم بـ HH/HL/LH/LL)، مربعات الرينج (النشط مظلل وبحد متصل، القديمة
منقّطة)، وصندوق معلومات فالزاوية العلوية يعرض N والترند الحالي وحدود الرينج النشط.
يُعاد الحساب فقط عند إغلاق شمعة جديدة (التأكيد أصلاً يحتاج شموع مغلقة).
