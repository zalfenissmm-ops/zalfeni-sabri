# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## مؤشر الدعم والمقاومة لـ MetaTrader 5 — `mt5/SupportResistance.mq5`

مؤشر MQL5 يخدم **مباشرة على شارت MT5** (موش بايثون، موش ملفات CSV).
يرسم **مناطق** دعم ومقاومة — موش خطوط — ويعطي لكل منطقة **نتيجة من 100**
باش تعرف علاش تركّز.

### التركيب

1. في MT5: `File → Open Data Folder`
2. حطّ الملف في `MQL5/Indicators/`
3. في MetaEditor: افتح الملف واضغط **Compile** (F7)
4. في MT5: `Insert → Indicators → Custom → SupportResistance`

### كيفاش يخدم

| الخطوة | الشرح |
|---|---|
| **1. النقاط** | قمم/قيعان (fractal swings). كل وحدة تعطي شريط من **الفتيل للجسم** — الفتيل يوري وين خذاو السيولة، الجسم يوري وين قبل السوق بالسعر. |
| **2. التجميع** | النقاط المتقاربة تولّي **منطقة وحدة**. المسافة تتقاس بالـ **ATR** موش بنسبة ثابتة، فالمؤشر يتأقلم روحو مع EURUSD والذهب والبيتكوين بلا ما تبدّل إعدادات. |
| **3. التقييم** | لمسات + قوة الارتداد (بالـ ATR) + الحداثة + الانقلاب − عقوبة الاختراق. |
| **4. الترتيب** | يرسم أقوى `TopN` فوق السعر وأقوى `TopN` تحتو برك. |

### قراءة الشارت

كل منطقة عندها لافتة: `النتيجة | عدد اللمسات | الحالة`

| الحالة | المعنى |
|---|---|
| `fresh` | تكوّنت وما تلمستش بعد |
| `tested` | تلمست وصمدت |
| `broken` | السعر غلق عبرها وقعد — **مرسومة بخط منقّط** |
| `flipped` | انكسرت وبعدها صمدت من الجهة الأخرى — **أقوى تأكيد** |

### الإعدادات المهمة

| الإعداد | الافتراضي | متى تبدّلو |
|---|---|---|
| `InpSwing` | 3 | تكبّرو = مناطق أقل وأهم. تصغّرو = تفاصيل أكثر. |
| `InpMerge` | 0.35 | مسافة الدمج بالـ ATR. تكبّرو = مناطق أعرض وأقل عدد. |
| **`InpMaxWidthATR`** | **0.7** | **الحدّ الأقصى لعرض المنطقة بالـ ATR — ما فماش منطقة تفوتو.** |
| **`InpMaxWidthPts`** | **0** | **حدّ أقصى بالنقاط. حطّ 10 مثلاً وما تشوفش منطقة أعرض من 10 نقاط. 0 = مطفي.** |
| `InpTopN` | 3 | عدد المناطق في كل جهة. |
| `InpMinScore` | 0 | حطّو 50 مثلاً باش يوري القوي برك. |
| `InpHideBroken` | false | خبّي المناطق المكسورة. |
| `InpAlertOnTouch` | false | تنبيه كي السعر يدخل منطقة. |

### ⚠️ ما يعاودش يرسم (No repaint)

- القمة/القاع ما تتستعملش كان بعد ما تتأكّد (`index + InpSwing`).
- التحليل على **الشموع المغلوقة برك** — الشمعة الجارية تتنحّى.

معناها المنطقة اللي تشوفها اليوم في الماضي هي نفسها اللي كانت متوفّرة وقتها،
وموش مرسومة بعد ما صار الشي.

### المناطق طالعة عريضة برشا؟

عرض المنطقة جاي من شريط **الفتيل-للجسم** متاع الشمعة، فشمعة كبيرة وحدها تعطي
منطقة عريضة. الحلّ:

1. حطّ **`InpMaxWidthPts = 10`** (ولا العدد اللي يعجبك) — حدّ صارم بالنقاط.
2. ولا صغّر **`InpMaxWidthATR`** من 0.7 لـ 0.3.
3. ولا صغّر **`InpMerge`** من 0.35 لـ 0.15 — يدمج أقلّ.

كي المنطقة تتقصّ، الطرف اللي يبقى هو **القمة** (كان مبنية من قمم) ولا **القاع**
(كان مبنية من قيعان) — لأن الحافة هاذي هي المستوى الحقيقي، والجسم هو اللي يتنحّى.
