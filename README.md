# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## ICT Gold Bot — ict_gold_bot.py

تطبيق كامل لاستراتيجية **ICT لتداول الذهب (XAU/USD)** في **ملف واحد**، بثلاث مراحل:

1. **جلب البيانات** — شموع حقيقية ومباشرة من منصة **MetaTrader 5** (D1 / H4 / H1 / M5).
2. **الاستراتيجية** — خطة التداول من المستند مكتوبة كقواعد قابلة للتنفيذ، خطوة بخطوة.
3. **الباك تستينق** — إعادة تشغيل بار-بار لآخر **30 يوم** على حساب **1000 دولار** بلوت **0.01**.

> **النقطة الأخيرة من الاستراتيجية (تسجيل الصفقة في يوميات التداول) تم حذفها كما طُلب**،
> لأنها عادة توثيق يدوية وليست قاعدة سوق قابلة للبرمجة — وجدول الصفقات في تقرير الباك
> تستينق هو البديل الآلي لها.

### حساب النقطة

اللوت 0.01 من الذهب = أونصة واحدة (حجم العقد 100 أونصة)، يعني حركة **1.00 دولار في سعر
الذهب = 1.00 دولار ربح أو خسارة** — وهي بالضبط "قيمة النقطة دولار" اللي اتبنى عليها الحساب.

### التشغيل على ويندوز (الأسهل)

**دبل-كليك على `run.bat`** — يلقى بايثون وحدو، يركّب حزمة MetaTrader5 إذا ناقصة، ويشغّل
الباك تستينق على 30 يوم. وإذا بايثون مش مركّب، يفتحلك صفحة التنزيل الصحيحة.

> حزمة `MetaTrader5` عندها نسخ لـ **Python 3.10 / 3.11 / 3.12 (64-bit) فقط** — النسخ
> الأحدث ما تخدمش معاها. وعلى ويندوز الأمر هو `python` مش `python3`.

تنجّم تمرّرلو أوامرك: `run.bat scan` أو `run.bat backtest --days 60 --breakeven-r 0`

### التشغيل بالأوامر

```bash
# باك تستينق على آخر 30 يوم من بيانات MT5 المباشرة
python ict_gold_bot.py backtest

# مع تفاصيل قمع الإشارات (وين تتصفّى الفرص)
python ict_gold_bot.py backtest --days 30 --verbose --csv-out trades.csv

# تصدير الشموع مرة وحدة، وبعدها الاشتغال بدون MT5
python ict_gold_bot.py export --csv-dir data
python ict_gold_bot.py backtest --source csv --csv-dir data

# الإعداد الحالي على البيانات المباشرة الآن
python ict_gold_bot.py scan
```

البيانات المباشرة تحتاج `pip install MetaTrader5` ومنصة MT5 شغّالة (ويندوز، أو لينكس عبر
Wine). وضع `--source csv` يشتغل بالمكتبة القياسية فقط. البرنامج يكتشف تلقائيًا فرق توقيت
سيرفر الوسيط عن UTC، ويحوّل كل شي لتوقيت لندن باش تتطابق مناطق القتل الزمنية مع المستند.

### القواعد المطبَّقة (كل خطوة من §5 في المستند)

| الخطوة | التطبيق في الكود |
|---|---|
| 1. الانحياز العام | هيكل BOS/CHoCH على D1، مع تأكيد توافق H4 |
| 1ب. علاوة/خصم | نقطة التوازن 50% لآخر مدى سعري (`--pd-tf`، الافتراضي H4) |
| 2. مجمعات السيولة | قمم/قيعان متساوية + سوينقات غير مُلامَسة على H1 |
| 3. منطقة القتل | لندن 07:00–10:00 ونيويورك 12:00–15:00 بتوقيت لندن |
| 4. تسييل السيولة | ذيل يخترق المستوى ويغلق راجع داخله (سوينق / مدى آسيا / مدى أمس) |
| 5. تغيّر الهيكل | CHoCH على M5 بعد التسييل، مشروط بحركة إزاحة (Displacement) |
| 6. منطقة الدخول | أوردر بلوك أو FVG يتقاطع مع OTE (61.8%–79%) |
| 7. وقف الخسارة | خلف نقطة التسييل/الكتلة بهامش ATR، وبحد أدنى معقول |
| 8. الهدف | أقرب مجمع سيولة معاكس، والصفقة تُرفض إذا نسبة العائد أقل من 1:2 |
| 9. إدارة الصفقة | نقل الوقف للتعادل عند 1R، وإغلاق جزئي اختياري (يحتاج لوت ≥ 0.02) |
| إدارة المخاطر §6 | حد 1% للصفقة، توقف بعد خسارتين متتاليتين في اليوم، سقف خسارة يومي 3% |

### دقة الباك تستينق

- **بدون نظرة مستقبلية**: كل قرار يتاخذ على إغلاق شمعة M5، والتنفيذ يصير في الشموع اللي
  بعدها فقط. الشموع الأكبر ما تُقرأ إلا بعد ما تُغلق فعليًا. (تم التحقق: حذف آخر 20 يوم من
  البيانات يعطي نفس الصفقات بالضبط في الفترة المشتركة.)
- **افتراض متحفّظ**: إذا لمست الشمعة وقف الخسارة والهدف في نفس البار، يُحتسب وقف الخسارة.
- **التكاليف**: السبريد يُقرا **تلقائيًا من الوسيط** عبر MT5 ويُخصم مرة واحدة لكل صفقة
  (تنجّم تفرضو بـ `--spread`)، والعمولة اختيارية (`--commission`).
- **توقيت السيرفر**: يُكتشف تلقائيًا ويُطبع مع ساعة التيرمينال باش تتأكد منو. إذا ما تطابقش
  مع ساعة Market Watch عندك، مرّر `--broker-utc-offset <ساعات>` وإلا مناطق القتل الزمنية
  باش تكون مزحلقة.
- **حجم اللوت ثابت 0.01** كما طُلب، لذلك المخاطرة بالدولار تتحدد بمسافة الوقف؛ وأي إعداد
  تتجاوز فيه المخاطرة 1% من الرصيد يُرفض بدل ما يُصغّر اللوت.

### ملاحظة على عدد الصفقات

الاستراتيجية مُطبّقة بحرفية المستند (انحياز + علاوة/خصم + تسييل + CHoCH + OTE + 1:2)،
وهذا فلتر ضيّق بطبيعته يعطي عدد صفقات قليل نسبيًا في الشهر. خيار `--verbose` يعرض قمع
الإشارات: كم بار عدّى كل شرط، وين بالضبط تتصفّى الفرص. ولو حبيت تخفّف الشروط:
`--no-poi` (دخول من OTE بدون كتلة/فجوة)، `--no-pd-filter`، `--no-mid-filter`،
`--tp-mode first-valid`، أو توسيع `--sweep-lookback` و `--choch-max-bars`.

### تنبيه

الكود أداة اختبار وتحليل، مش توصية استثمارية، وما ينفّذش صفقات حقيقية على الحساب.
نتائج الباك تستينق على بيانات تاريخية ما تضمنش نتائج مستقبلية — نفس التنبيه المذكور في
المستند الأصلي.
