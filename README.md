# SMC — أدوات Smart Money Concepts

ملف بايثون واحد `smc.py`، **بلا أي مكتبة خارجية**. يحتاج Python 3.10 أو أحدث.

القواعد الكاملة للاستراتيجية موجودة في **[STRATEGY.md](STRATEGY.md)** — اقراها قبل الكود.

## ثلاث أوامر

```bash
python3 smc.py trend    data.csv    # الاتجاه وقوّتو
python3 smc.py scan     data.csv    # الإعداد الموجود في الشارت توّة
python3 smc.py backtest data.csv    # يطبّق القواعد شمعة بشمعة على التاريخ
```

ملف CSV لازم يكون فيه سطر عناوين بالأعمدة: `date,open,high,low,close`

---

## 1. `trend` — تحديد الاتجاه

يجمع ثلاث إشارات بدل ما يعتمد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من الـ EMA**: فوقه = صاعد، تحته = هابط.
3. **ADX**: يقيس **قوّة** الترند ويفرّق بين ترند حقيقي وسوق عرضي.

```bash
python3 smc.py trend data.csv --ema 50 --adx-period 14 --swing 5
```

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

الاتجاه يتحدّد بتصويت بين البنية وموقع السعر من الـ EMA، والـ ADX يقولك تثق فيه ولا لا
(أقل من 20 = عرضي، 20–25 = يتكوّن، فوق 25 = قوي).

---

## 2. `scan` — الوضع الحالي في الشارت

يكشف مكوّنات SMC حوالي آخر CHoCH: سيولة (Equal Highs/Lows)، تصيّد السيولة،
هيكل السعر (BOS/CHoCH)، أوردر بلوك، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم.

```bash
python3 smc.py scan data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50%) وداخل الأوردر بلوك
ولا الفجوة السعرية.

## 3. `backtest` — المتداول الافتراضي

يمشي على الشموع وحدة وحدة كيف بنادم:

```
لكل شمعة:
  1. يدير الصفقات المفتوحة (ستوب، جني جزئي، نقل للتعادل، ستوب متحرك، هدف)
  2. يشوف إذا أمر الـ Limit تعبّى
  3. وبعد برك يدوّر على إعداد جديد
```

**بلا نظرة للمستقبل**: كل ميزة (قمة، مجمّع سيولة، حدث هيكل، FVG) عندها رقم الشمعة
اللي **تأكّدها**. القمة في شمعة `j` ما تولّيش معروفة كان في `j+window`، والإشارة في
شمعة `i` ما تنجّمش تتعبّى قبل `i+1`. وكي شمعة وحدة تلمس الستوب والهدف في نفس الوقت
→ **الستوب يفوز**.

### الاستخدام

```bash
python3 smc.py backtest data_15m.csv --balance 100 --lot 0.01 \
    --pip-value 1 --pip-size 1 --export trades.csv
```

الملف هو إطار **الدخول** (15m). إطار الاتجاه (4H) يتبنى منّه بـ `--htf-mult 16`
(16 شمعة 15 دقيقة = 4 ساعات). للـ 5m استعمل `--htf-mult 48`.

### نموذج الحساب

```
الربح/الخسارة = حركة السعر ÷ pip-size × pip-value × (lot ÷ 0.01)
```

الافتراضي = حساب **100$**، لوت **0.01**، ونقطة وحدة تساوي **1$** (يعني حركة 1.0
في السعر = 1$ — كيف الذهب). للفوركس بدّل `--pip-size 0.0001` و`--pip-value` حسب الزوج.

### أهم الخيارات

| الخيار | الافتراضي | يعمل شنو |
|---|---|---|
| `--min-rr` | 3.0 | يرفض أي إعداد يعطي أقل من 1:3 |
| `--confirm` | choch | `choch` = انعكاس فقط، `any` = يقبل BOS زادة |
| `--choch-window` | 12 | قدّاش شمعة يستنّى التصيّد في التأكيد |
| `--min-adx` | 0 (مطفي) | فلتر قوة الترند على الإطار الكبير |
| `--no-bias-filter` | — | يتداول الجهتين بلا فلتر اتجاه (للمقارنة) |
| `--no-pd-filter` | — | يلغي شرط Premium/Discount (للمقارنة) |
| `--partial-rr` / `--partial-pct` | 2.0 / 50 | الجني الجزئي ونقل الستوب للتعادل |
| `--max-risk-pct` | 0 (مطفي) | يتجاوز الصفقات اللي مخاطرتها أكبر من هالنسبة |
| `--cost` | 0 | السبريد + العمولة بالدولار للصفقة الكاملة |

`python3 smc.py backtest --help` يوريك الباقي.

### قسمين مهمّين في التقرير

- **Risk reality check**: متوسط المخاطرة بالدولار وكنسبة من الحساب. بلوت ثابت 0.01
  على حساب 100$، ستوب 8 نقاط = **8% مخاطرة**، موش 1%. البرنامج ينبّهك كي تفوت 2%.
- **Funnel**: قدّاش تصيّد سيولة تلقى، وقدّاش إعداد اترفض وعلاش (`no_confirmation`،
  `wrong_pd_zone`، `rr_below_minimum`...). هذا يقولك أي شرط هو اللي يخنق الاستراتيجية
  قبل ما تبدا تبدّل في الأرقام.

### ملاحظات على الدقّة

- التراجع (Drawdown) محسوب على الأرباح **المحقّقة** (بعد إغلاق كل صفقة)، موش على
  الحقوق اللحظية داخل الصفقة.
- التنفيذ مثالي: ما فماش انزلاق سعري (Slippage) ولا رفض أوامر. استعمل `--cost` باش
  تقرّب من الواقع.
- حدود الخسارة اليومية والأسبوعية تحتاج عمود `date` مقروء؛ إذا ما تقراش التواريخ
  البرنامج ينبّهك ويطفي الحدود هذي.

## بنية الملف

`smc.py` مقسّم لثمن أقسام معلّمين بتعليقات:

| القسم | فيه شنو |
|---|---|
| 1. data | الشموع، قراءة CSV، قراءة التواريخ |
| 2. math | EMA، تنعيم Wilder، ADX |
| 3. detectors | القمم، الهيكل (BOS/CHoCH)، السيولة، FVG، الأوردر بلوك |
| 4. trend | أمر `trend` |
| 5. scan | أمر `scan` |
| 6. signals | الشروط الستة كإشارات بلا نظرة للمستقبل |
| 7. backtest | الفلوس، قواعد المخاطرة، حلقة المتداول، التقرير |
| 8. cli | قراءة الأوامر والخيارات |
