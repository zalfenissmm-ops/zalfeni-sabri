# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## Liquidity Map — mt5/LiquidityMap.mq5

مؤشر **MetaTrader 5** يرسم مناطق السيولة الراقدة على الشارت مباشرة، **لحظيًا**.
أداة رسم خريطة فقط — **ما فيه لا دخول، لا ستوب، لا تارجت، لا إشارات تداول**.

### شنوة يرسم

| المصطلح | المعنى |
|---|---|
| **BSL** (Buy-Side Liquidity) | سيولة **شرائية** فوق القمم — ستوبات البايعين والأوامر المعلّقة |
| **SSL** (Sell-Side Liquidity) | سيولة **بيعية** تحت القيعان — ستوبات الشارين |
| **PD** | مستوى اليوم السابق (PDH / PDL) |
| **PW** | مستوى الأسبوع السابق (PWH / PWL) |

### الحالات — هذا هو الجزء "اللحظي"

- **خط ملوّن ممدود لليمين** = سيولة **مازالت راقدة** (`untapped`). هذي هي الأهداف الحيّة.
- **خط ذهبي سميك + `RAID`** = الشمعة اللي تتكوّن **توّا** تخترق البِركة. مؤقتة — تتحسم كي تسكّر الشمعة.
- **خط رمادي منقّط + `swept`** = ويك خذا السيولة ورجع سكّر وراها = **تصيّد سيولة**. يتحيّى بعد `SweptKeepBars` شمعة.
- **يتشطب من الشارت** = السعر سكّر ورا المستوى (`claimed`) — السيولة تاخذت وخلاص، المستوى ما عادش بِركة.

### التنقيط

كل بِركة عندها لصاقة كيما `BSL x3  S72  1.3ATR`:

- `x3` = عدد القمم/القيعان المتساوية اللي كوّنت البِركة (كل ما زادت، كل ما تكدّست الستوبات)
- `S72` = النقاط من 100: التلامسات + دقّة التساوي + بونص PDH/PDL/PWH/PWL + عمر البِركة
- `1.3ATR` = البُعد على السعر الحالي بوحدة ATR

والترتيب على الشارت يمشي بـ **قوة الجذب اللحظية**:

```
pull = score / (1 + distance_in_ATR)
```

يعني بِركة قوية أما بعيدة برشا ما تغلبش بِركة متوسطة وقريبة — وهذا هو معنى "لحظي".

### اللوحة (فوق يسار)

```
Liquidity map  3/3   ATR 0.00081
Nearest BSL  1.09420   +1.24 ATR   S72 x3
Nearest SSL  1.09180   -0.93 ATR   S64 x2
RAID NOW     BSL 1.09420
```

### التركيب

1. حطّ `LiquidityMap.mq5` في مجلّد الداتا متاع MT5:
   `File → Open Data Folder → MQL5 → Indicators`
2. افتح MetaEditor، افتح الملف، واضغط **F7** باش تكومبيلي.
3. في MT5: `Navigator → Indicators → LiquidityMap` → اسحبو على الشارت.

### الإعدادات المهمّة

| الإعداد | الافتراضي | شنوة يعمل |
|---|---|---|
| `LeftBars` / `RightBars` | 3 / 3 | نافذة اكتشاف القمم/القيعان. كبّرهم = برك أقل وأهم |
| `EqTolATR` | 0.15 | مدى التساوي بالـ ATR. كبّرو = يجمّع قمم أبعد في بِركة وحدة |
| `MinTouches` | 1 | حطّو **2** كان تحب **غير** القمم/القيعان المتساوية (Equal Highs/Lows) |
| `MaxPools` | 12 | عدد البرك لكل جهة — نقّصو كان الشارت تعبّى |
| `MinScore` | 0 | فلترة بالجودة، مثلاً 50 يخلّي غير البرك القوية |
| `ShowZoneBox` | false | يرسم منطقة بدل خط |
| `AlertOnRaid` | false | تنبيه كي تبدا بِركة تتصاد |

### ملاحظات تقنية على الدقة

- **بلا repainting**: كل بِركة تولّي معروفة غير بعد ما تسكّر نافذة الـ `RightBars` متاعها، وحالتها تتحسب من الشموع اللي **جات بعدها** فقط. ما فماش نظرة للمستقبل.
- **التوليرانس بالـ ATR متاع نفس الشمعة**، موش ATR اليوم مطبّق على تاريخ قديم — هكا التذبذب كي يتبدّل، الحساب يبقى صحيح، ونفس الإعدادات تخدم على الذهب والبيتكوين واليورو بلا تعديل.
- **تجميع (clustering)**: 3 قمم متساوية = بِركة **وحدة** بـ `x3`، موش زوز برك منفصلين.
- **الاختراق يتقاس من `level + tolerance`**، موش من القمة بالضبط — هكا قمة أعلى بشوية تندمج في نفس البِركة بدل ما تتحسب تصيّد غالط.
- **الحدود**: بيانات الشموع ما تقيسش السيولة الحقيقية، تستنتج **موقعها** من الهيكل. الحجم الحقيقي متاع الأوامر يلزمو order book (L2/DOM).
