# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## مؤشر MT5 — `mt5/OB_Sweep_FVG.mq5`

مؤشر MQL5 يرسم الأوردر بلوك مباشرة على الشارت ويشتغل على **جميع الفريمات**.

### الشروط (v1.20 — فلاتر جودة حقيقية)

الشمعة `1` = شمعة الأوردر بلوك (شمعة السويب):

| الشرط | الاتجاه الصاعد | الاتجاه الهابط |
|---|---|---|
| 1. كنس سيولة حقيقية | يكسر **قاع سوينق مؤكّد** (Pivot بقوة `InpPivotStrength`) **ما تكسرش قبل**، والإغلاق يرجع فوقه | يكسر **قمة سوينق مؤكّدة** والإغلاق يرجع تحتها |
| 2. لون الشمعة | حمراء | خضراء |
| 3. شفت يكسر الهيكل | إغلاق **فوق أعلى قمة** بين السوينق وشمعة السويب، خلال `InpMSSBars` شموع، بجسم ≥ `InpDisplaceATR × ATR` | إغلاق **تحت أدنى قاع** بنفس الشروط |
| 4. فجوة (Imbalance/FVG) | فجوة داخل موجة الاندفاع ≥ `InpMinFVGATR × ATR` | نفس الشيء بالمقلوب |

- الأربعة → منطقة أوردر بلوك تترسم. غاب أي واحد → **ما يترسم شيء**.
- الشرط 1 هو اللي يقتل الإشارات الوهمية: قبل كنّا نعتبر أي ذيل ينزل تحت أدنى قاع في آخر 10 شموع = سويب،
  وهذا يصير في كل شمعة تقريبًا. توّا لازم قاع/قمة **سوينق** مؤكّدة وما تكسرتش.
- الشرط 3 يمنع الإشارات في السوق العرضي: الشفت لازم يكسر الهيكل بشمعة قوّتها ≥ 0.8 ATR.
- الفجوة تتقاس **نسبة لـ ATR** مش نقاط ثابتة → نفس السلوك على كل الفريمات وكل الأزواج.

### الرسم

- مستطيل بتعبئة فاتحة **خلف الشموع** + إطار واضح (`InpBorderWidth=2`) **قدّام الشموع**.
- الفجوة: إطار منقّط بلا تعبئة. خط السيولة المكنوسة: منقّط رفيع.
- ليبل واحد قصير على يمين المنطقة، ولآخر `InpMaxLabels` مناطق فقط.
- المنطقة تتمدّ لليمين لين تنكسر → `Bull OB / Bear OB` ← تزيد `•` كي السعر يدخلها ← تنمحي كي شمعة تغلق برّاها.
- `InpShowMidLine` يزيد خط 50% للمنطقة (مطفي افتراضيًا).
- `InpFillZones=false` = إطارات فقط (أنظف على الشارت الغامق).

### أهم الإعدادات

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpPivotStrength` | 3 | قوة السوينق (شموع من كل جهة). زيدها = فرص أقل وأقوى |
| `InpSweepSearch` | 40 | مدى البحث على السوينق |
| `InpRequireMSS` | true | الشفت لازم يكسر الهيكل (طفّيه = شروط أخفّ) |
| `InpMSSBars` | 3 | عدد الشموع المسموحة للشفت |
| `InpDisplaceATR` | 0.8 | أدنى قوة لشمعة الشفت نسبة لـ ATR |
| `InpMinFVGATR` | 0.15 | أدنى حجم للفجوة نسبة لـ ATR |
| `InpNoOverlap` / `InpOverlapPct` | true / 50 | المنطقة الجديدة تحلّ محلّ القديمة في نفس المستوى |
| `InpHideBroken` | true | المنطقة المكسورة تنمحي |
| `InpMaxZones` / `InpMaxLabels` | 10 / 4 | حدّ المناطق والليبلات |
| `InpAlertNew` / `InpAlertRetest` | false | تنبيه عند تكوّن منطقة / عند رجوع السعر إليها |

**تحبّ فرص أكثر؟** نقّص `InpPivotStrength` لـ 2 و`InpDisplaceATR` لـ 0.5.
**تحبّ فرص أقلّ وأنقى؟** زيد `InpPivotStrength` لـ 4-5 و`InpDisplaceATR` لـ 1.2.

### التركيب

1. انسخ `OB_Sweep_FVG.mq5` إلى `MQL5/Indicators/` (‏MT5 → File → Open Data Folder).
2. MetaEditor → `F7`.
3. Navigator → Indicators → اسحبه على الشارت.

المؤشر يوفّر مخزنين للأسهم: `0` = أوردر بلوك صاعد، `1` = هابط — للاستدعاء من إكسبيرت عبر `iCustom()`
(يخدمو حتى كي تكون الأسهم مخفية).

> ملاحظة: المنطقة تظهر بعد تأكّد الشفت (حتى `InpMSSBars + 2` شمعة)، وهذا مقصود — بلا تأكيد ترجع الإشارة وهمية.

## `mt5/ob_scan.py` — نفس القواعد على ملف CSV

باش تعرف الأوردر بلوك **بالأرقام بالضبط** بلا ما تفتح المؤشر (أو باش تتثبّت منه):

1. في MT5: `View → Symbols` (‏Ctrl+U) → اختار الزوج → تبويب **Bars** → اختار الفريم → **Export** → يسجّل CSV.
2. شغّل:

```bash
python3 mt5/ob_scan.py XAUUSD_M15.csv
```

مثال على المخرجات:

```
الشموع: 336   من 2026.09.08 00:00   إلى 2026.09.11 11:45   آخر سعر: 4379.58
مناطق حيّة: 1   |   مكسورة: 0

النوع     الحالة  من          إلى         الفجوة FVG            المسافة   الوقت
Bull OB   LIVE    4316.06     4331.16     4331.16 - 4356.66     -55.97    2026.09.11 06:15
```

نفس الإعدادات متاع المؤشر متوفرة كخيارات: `--pivot 3 --displace 0.8 --fvg-atr 0.15 --mss-bars 3`،
و`--no-mss` يلغي شرط كسر الهيكل، و`--show-broken` يوري حتى المناطق المكسورة.
يقبل ملف MT5 (‏`<DATE> <TIME> <OPEN> ...`) وأي CSV عادي فيه `date,open,high,low,close`.

## `mt5/Draw_OB_Levels.mq5` — سكريبت يرسم مناطق جاهزة على الشارت

سكريبت (مش مؤشر) تسحبه على الشارت فيرسم المناطق اللي تكتبها في الإعدادات مباشرة:
مستطيل بتعبئة خفيفة خلف الشموع + إطار واضح + ليبل بالأسعار.

- المكان: `MQL5/Scripts/` (مش `Indicators`) → `F7` في MetaEditor → Navigator → Scripts → اسحبه على الشارت.
- صيغة كل سطر: `<القاع> <القمة> <buy|sell|fvg> <الاسم>` — مثال:

```
4423 4431 sell Bear OB
4395 4402 sell Bear OB
4327 4345 fvg  Imbalance / FVG
4298 4318 buy  Bull OB
```

- `InpBarsBack` بداية المربّع لليسار، `InpExtendBars` مدّه لليمين، `InpClearOld` يمسح رسم السكريبت القديم.
- للاكتشاف الآلي استعمل المؤشر `OB_Sweep_FVG.mq5`؛ هذا السكريبت للرسم اليدوي لمستويات معروفة.
