# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## الباك تيست — `backtest.py` + `smc_signals.py`

`smc_signals.py` يحوّل الشروط الستة لإشارات، و`backtest.py` يمشي على الشموع
وحدة وحدة كيف متداول حقيقي:

```
لكل شمعة:
  1. يدير الصفقات المفتوحة (ستوب، جني جزئي، نقل للتعادل، ستوب متحرك، هدف)
  2. يشوف إذا أمر الـ Limit تعبّى
  3. وبعد برك يدوّر على إعداد جديد
```

**بلا نظرة للمستقبل**: كل ميزة (قمة، مجمّع سيولة، حدث هيكل، FVG) محسوبة مسبقًا
مع رقم الشمعة اللي **تأكّدها**. القمة في شمعة `j` ما تولّيش معروفة كان في `j+window`،
والإشارة في شمعة `i` ما تنجّمش تتعبّى قبل `i+1`. وكي شمعة وحدة تلمس الستوب والهدف
في نفس الوقت → **الستوب يفوز**.

### الاستخدام

```bash
python3 backtest.py data_15m.csv --balance 100 --lot 0.01 --pip-value 1 --pip-size 1 \
    --export trades.csv
```

الملف هو إطار **الدخول** (15m). إطار الاتجاه (4H) يتبنى منّه بـ `--htf-mult 16`
(16 شمعة 15 دقيقة = 4 ساعات). للـ 5m استعمل `--htf-mult 48`.

### نموذج الحساب

```
الربح/الخسارة = حركة السعر ÷ pip-size × pip-value × (lot ÷ 0.01)
```

الإعدادات الافتراضية = حساب **100$**، لوت **0.01**، ونقطة واحدة تساوي **1$**
(يعني حركة 1.0 في السعر = 1$ — كيف الذهب). للفوركس بدّل `--pip-size 0.0001`
و`--pip-value` حسب الزوج.

### أهم الخيارات

| الخيار | الافتراضي | يعمل شنو |
|---|---|---|
| `--min-rr` | 3.0 | يرفض أي إعداد يعطي أقل من 1:3 |
| `--confirm` | choch | `choch` = انعكاس فقط، `any` = يقبل BOS زادة |
| `--choch-window` | 12 | قدّاش شمعة يستنّى التصيّد في التأكيد |
| `--min-adx` | 0 (مطفي) | فلتر قوة الترند على الإطار الكبير |
| `--no-bias-filter` | — | يتداول الجهتين بلا فلتر اتجاه (للمقارنة) |
| `--no-pd-filter` | — | يلغي شرط Premium/Discount (للمقارنة) |
| `--partial-rr` / `--partial-pct` | 2.0 / 50 | الجني الجزئي ونقل الستوب للتعادل |
| `--max-risk-pct` | 0 (مطفي) | يتجاوز الصفقات اللي مخاطرتها أكبر من هالنسبة |
| `--cost` | 0 | السبريد + العمولة بالدولار للصفقة الكاملة |

### المخرجات

زوز أقسام مهمّين برشا غير الأرباح:

- **Risk reality check**: متوسط المخاطرة بالدولار وكنسبة من الحساب. بلوت ثابت
  0.01 على حساب 100$، ستوب 8 نقاط = **8% مخاطرة**، موش 1%. البرنامج ينبّهك
  كي المخاطرة تفوت 2%.
- **Funnel**: قدّاش تصيّد سيولة تلقى، وقدّاش إعداد اترفض وعلاش (`no_confirmation`،
  `wrong_pd_zone`، `rr_below_minimum`...). هذا يقولك أي شرط هو اللي يخنق
  الاستراتيجية قبل ما تبدا تبدّل في الأرقام.

### ملاحظات على الدقة

- التراجع (Drawdown) محسوب على الأرباح **المحقّقة** (بعد إغلاق كل صفقة)، موش على
  الحقوق اللحظية داخل الصفقة.
- التنفيذ مثالي: ما فماش انزلاق سعري (Slippage) ولا رفض أوامر. استعمل `--cost`
  باش تقرّب من الواقع.
- حدود الخسارة اليومية والأسبوعية تحتاج عمود `date` مقروء؛ إذا ما تقراش
  التواريخ البرنامج ينبّهك ويطفي الحدود هذي.
