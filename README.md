# Trend Identifier — أداة تحديد الترند

أداة بايثون (بدون مكتبات خارجية) لتحديد اتجاه السوق وقوته من بيانات الشموع (OHLC)،
باستخدام ثلاث إشارات متكاملة بدل الاعتماد على مؤشر واحد:

1. **بنية القمم والقيعان**: قمم/قيعان أعلى (صاعد) مقابل قمم/قيعان أدنى (هابط).
2. **موقع السعر من المتوسط المتحرك الأسي (EMA)**: فوقه = صاعد، تحته = هابط.
3. **ADX**: لقياس **قوة** الترند وتمييز الترند الحقيقي عن السوق العرضي.

## الاستخدام

ملف CSV يحتوي على الأعمدة: `date,open,high,low,close`

```bash
python3 trend_identifier.py data.csv --ema 50 --adx-period 14 --swing 5
```

### مثال على المخرجات

```
Direction : Uptrend
Strength  : strong (ADX=32.10)
Price vs EMA50: up (close=140.53000, ema=131.44000)
Swing structure: up
```

- **Direction**: Uptrend / Downtrend / Sideways / Unclear
- **Strength**: قوة الترند حسب ADX (weak/ranging < 20، developing 20-25، strong > 25)
- **Swing structure**: نمط القمم/القيعان الأخير (up / down / mixed / unknown إذا لم تتوفر بيانات كافية)

## ملاحظة

لا تعتمد على مؤشر واحد فقط. الإشارة الأقوى هي توافق الإشارات الثلاث معًا، والقوة (ADX)
تخبرك متى تثق بالاتجاه ومتى يكون السوق عرضيًا وغير موثوق للتداول باتجاه واحد.

## SMC Strategy — smc_strategy.py

أداة ثانية تكتشف إعدادات **Smart Money Concepts** من نفس نوع ملفات CSV:
سيولة (Equal Highs/Lows)، تصيّد السيولة (Liquidity Sweep)، هيكل السعر (BOS/CHoCH)،
أوردر بلوك (Order Block)، فجوة سعرية (FVG)، ومنطقة العلاوة/الخصم (Premium/Discount).

### الاستخدام

```bash
python3 smc_strategy.py data.csv --swing 1 --tolerance 0.0015 --impulse 1.8
```

- `--swing`: نافذة اكتشاف القمم/القيعان (كل ما قلّت، كل ما اكتشفت قمم/قيعان أقرب لبعضها).
- `--tolerance`: نسبة التفاوت المسموحة لاعتبار قمتين/قاعين "متساويين" = مجمع سيولة.
- `--impulse`: مضاعف حجم الشمعة عشان تعتبر "اندفاعية" لتحديد الأوردر بلوك.

### مثال على المخرجات

```
Direction        : SHORT (CHoCH at candle #13)
Liquidity sweep  : {'index': 11, 'kind': 'high', 'level': 81.0}
Order block      : {'index': 12, 'kind': 'bearish_ob', 'top': 80.0, 'bottom': 76.0}
FVG              : {'index': 13, 'kind': 'bearish', 'bottom': 65.0, 'top': 76.0}
Equilibrium (50%): 59.50000
In premium zone   : True
In order block   : True
In FVG           : False
Entry ready      : True
Suggested SL     : 81.08100
Suggested TP     : 37.96200
```

`Entry ready: True` يعني السعر رجع لمنطقة العلاوة (فوق 50% من الهبوط) وداخل الأوردر بلوك أو الفجوة السعرية —
نفس النقطة اللي كانت متوضحة في خريطة الاستراتيجية.

## مؤشر MT5 — `mt5/OB_Sweep_FVG.mq5`

مؤشر MQL5 يطبّق طريقة استخراج الأوردر بلوك مباشرة على الشارت، ويشتغل على **جميع الفريمات**
(يقرأ شموع الفريم الحالي فقط، فما فمّاش أي إعداد مربوط بفريم معيّن).

### القاعدة المطبّقة

الشمعة `1` = شمعة الأوردر بلوك، `2` = شمعة الشفت، `3` = شمعة الاندفاع:

| الشرط | الاتجاه الصاعد | الاتجاه الهابط |
|---|---|---|
| 1. كنس السيولة (Liquidity Sweep) | `low[1]` تحت أدنى قاع في آخر N شمعة **و** الإغلاق يرجع فوقه | `high[1]` فوق أعلى قمة في آخر N شمعة **و** الإغلاق يرجع تحتها |
| 2. لون الشمعة | حمراء (اختياري) | خضراء (اختياري) |
| 3. الشفت (Shift) | `close[2] > high[1]` وشمعة صاعدة | `close[2] < low[1]` وشمعة هابطة |
| 4. الفجوة (Imbalance / FVG) | `low[3] > high[1]` | `high[3] < low[1]` |

- تحقّق **1+2+3+4** → `Valid OB` (مستطيل ملوّن) + مربّع `FVG` فوقه.
- تحقّق **1+2+3** بدون فجوة → `InValid OB` (رمادي) — نفس الحالة اللي وضّحها الفيديو.
- **سويب بدون شفت** → ما يترسم شيء (ليس أوردر بلوك).

حدود المنطقة: من `low[1]` إلى `high[1]` (أو الجسم فقط إذا عطّلت `InpWickToWick`)،
والفجوة من `high[1]` إلى `low[3]` في الصاعد والعكس في الهابط.

### حالة المنطقة

- `Valid OB` → لسّه ما تلمّستش.
- `Valid OB (tested)` → السعر دخل للمنطقة.
- `OB Broken` → شمعة أغلقت تحت المنطقة (صاعد) أو فوقها (هابط) → المنطقة تتوقّف عند شمعة الكسر ويتغيّر لونها.

### التركيب

1. انسخ `OB_Sweep_FVG.mq5` إلى `MQL5/Indicators/` داخل مجلّد بيانات المنصّة
   (MT5 → File → Open Data Folder).
2. افتح الملف في MetaEditor واضغط `F7` للتصريف (Compile).
3. في MT5: Navigator → Indicators → `OB_Sweep_FVG` → اسحبه على الشارت.

### أهم الإعدادات

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpSweepLookback` | 10 | عدد الشموع اللي يدوّر فيها على السيولة المكنوسة |
| `InpRequireOppColor` | true | اشتراط أن شمعة الأوردر بلوك معاكسة للاتجاه |
| `InpRequireShift` | true | اشتراط إغلاق شمعة الشفت خارج شمعة الأوردر بلوك |
| `InpRequireFVG` | true | بدون فجوة = `InValid` |
| `InpMinFVGPoints` | 0 | أدنى حجم للفجوة بالنقاط (فلترة الفجوات الصغيرة) |
| `InpWickToWick` | true | المنطقة بالذيول؛ `false` = بالجسم فقط |
| `InpShowInvalid` | true | إظهار/إخفاء الأوردر بلوك غير الصحيح |
| `InpExtendBars` | 8 | مدّ المناطق N شمعة لليمين |
| `InpMaxZones` | 30 | أقصى عدد مناطق تبقى على الشارت |
| `InpAlertNew` / `InpAlertRetest` | false | تنبيه عند تكوّن أوردر بلوك جديد / عند رجوع السعر إليه |

المؤشر يوفّر أيضًا مخزنين (buffers) للأسهم: `0` = أوردر بلوك صاعد، `1` = هابط،
تنفع للاستدعاء من إكسبيرت عبر `iCustom()`.

> ملاحظة: على الفريمات الصغيرة قلّل `InpSweepLookback` وارفع `InpMinFVGPoints` لتصفية الضجيج.
