# مؤشر MT5 — ستراتيجية الفيديو (FVG + سيولة + كسر هيكلي)

`SMC_VideoStrategy.mq5` — مؤشر MetaTrader 5 يطبّق **نفس الموديل** اللي في الفيديو:
يرسم الشروط وقت ما تتحقّق، وكي يكمّلوا الثلاثة يرسم الصفقة بنفس الشكل
(مربع أخضر للهدف + مربع أحمر للمخاطرة + خطوط Entry / SL / TP #1 / TP).

يخدم على **كل الأزواج وكل الفريمات** — ما فمّاش أي قيمة ثابتة بالنقاط،
كل شي محسوب نسبة لارتفاع الفجوة السعرية.

## الشروط الثلاثة كيما يحسبهم المؤشر

| الشرط | التطبيق في الكود |
|---|---|
| ١- فجوة سعرية (FVG) | عدم توازن على ٣ شمعات: `low[j] > high[j-2]` (صاعدة) أو `high[j] < low[j-2]` (هابطة). الفجوة تبقى صالحة حتى تسكّر شمعة تحت قاعها (أو فوق قمّتها للهابطة). |
| ٢- سيولة (LQ) | آخر قاع/قمّة مؤكّدة (fractal بنافذة `InpSwingWindow`). لازم الشمعة **تكنس** المستوى (الويك يعدّي تحتو) **و** الويك يوقف داخل الفجوة. |
| ٣- كسر هيكلي (BOS) | آخر قمّة مؤكّدة (للشراء) = **الهدف**. |
| الدخول | بعد ما تسكّر شمعة الكنس، يتحطّ **أمر Stop على مستوى السيولة** (Buy Stop فوقو للشراء). يتنفّذ كي يرجع السعر يعدّي المستوى خلال `InpReclaimBars` شمعات — كيما في الفيديو بالضبط. كان السعر يهبط تحت الستوب قبل، الإعداد يتلغى. |

**مستويات الصفقة (نفس حساب الفيديو):**

```
Entry = مستوى السيولة المكنوس (LQ)
SL    = أدنى نقطة بين قاع الفجوة وويك الكنس  −  هامش
TP    = مستوى الكسر الهيكلي (BOS)            +  هامش
TP #1 = نص المسافة بين الدخول والهدف
الهامش = InpBufferPercent % من ارتفاع الفجوة (افتراضي 25%)
```

### مطابقة مع صفقة الفيديو (XAUUSD 1H)

| | الفيديو | المؤشر بالإعدادات الافتراضية |
|---|---|---|
| Entry | 4,364.48 | 4,364.16 (مستوى السيولة) |
| SL | 4,340.29 | ≈ 4,340.75 |
| TP #1 | 4,383.88 | ≈ 4,382.95 |
| الهدف (BOS) | 4,402.36 | ≈ 4,401.75 |
| النتيجة | 378 pips | ≈ 376 pips (1.6R) |

## التركيب

1. انسخ `SMC_VideoStrategy.mq5` لـ:
   `<مجلد بيانات MT5>/MQL5/Indicators/` — من المنصّة: **File → Open Data Folder**.
2. افتح MetaEditor (F4) → افتح الملف → **Compile** (F7).
3. في MT5: **Navigator → Indicators → SMC_VideoStrategy** → سحب على الشارت.

## الإعدادات

**الستراتيجية**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpLookbackBars` | 5000 | عمق التاريخ اللي يحلّلو (5000 شمعة = ~7 أشهر على H1). زيدو كان تحبّ تاريخ أطول |
| `InpSwingWindow` | 3 | نافذة القمم/القيعان — زيدها = قمم أكبر وإشارات أقلّ |
| `InpReclaimBars` | 3 | كم شمعة يبقى فيها أمر الدخول صالح |
| `InpAtrPeriod` | 14 | فترة الـ ATR (يتقاس بيه حجم الفجوة) |
| `InpMinFvgAtrPct` | 30 | أصغر فجوة مقبولة = 30% من الـ ATR — يقتل الفجوات الصغيرة |
| `InpFvgMaxAgeBars` | 500 | يتجاهل الفجوات الأقدم من هكا (0 = بلا حدّ) |
| `InpRequireCE` | false | يشترط الويك يوصل لنص الفجوة — فلتر أقوى |
| `InpAllowBuys` / `InpAllowSells` | true | شراء / بيع |
| `InpMinRR` | 0 | أدنى نسبة ربح/مخاطرة (مثلاً 1.5) |
| `InpEntryAtClose` | false | true = الدخول بإغلاق شمعة الاسترجاع بدل مستوى السيولة |
| `InpBufferPercent` | 25 | هامش الستوب/الهدف كنسبة من ارتفاع الفجوة |
| `InpTP1Percent` | 50 | موقع TP #1 |

**الرسم**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpMaxTrades` | 30 | كم صفقة قديمة تتبقى مرسومة (0 = الكل) |
| `InpTradeBoxBars` | 30 | عرض مربّع الصفقة بالشمعات |
| `InpShowCurrentLevels` | true | خطّ LQ وخطّ BOS الحاليين ممدودين لليمين |
| `InpAutoContrast` | true | يختار ألوان الرسم حسب خلفية شارتك. **ما يبدّلش ألوان الشارت** |
| `InpPipSize` | 0 (تلقائي) | حجم الـ pip لحساب النتيجة |
| `InpAlertPopup` / `InpAlertPush` | true / false | تنبيه المنصّة / إشعار الموبايل |

الألوان كلها متغيّرة من الإعدادات (`InpFvgFill`, `InpProfitFill`, `InpRiskFill`, …).

## التحقّق — `tests/run_tests.sh`

الكود يتكومپايلي ويتشغّل خارج MetaTrader (`mt5/tests/`) على جوج داتا:

1. **سيناريو الفيديو** → يكشف صفقة شراء وحدة: Entry 4364.16 · SL 4340.75 · TP1 4382.95 ·
   TP 4401.75 · النتيجة `+376 PIPS 1.61R`، ويرسم **21 كائن** برك (مربّع الفجوة + LQ + BOS +
   مربّع الصفقة + النتيجة) — 17 كائن للصفقة الوحدة.
2. **72,000 شمعة عشوائية** → سوق بلا أفضلية، والمؤشر يعطي **+0.039R في المعدّل**
   على 1,688 صفقة، يعني الحساب نظيف بلا look-ahead.

⚠️ الاختبار الثاني **موش دليل على ربحية الستراتيجية** — هو اختبار صحّة للكود برك.
الربحية الحقيقية تتقاس بـ Strategy Tester على داتا السوق الحقيقية متاعك.

## ملاحظات

- المؤشر يحسب **مرّة كل شمعة مغلقة** (موش كل تيك) — خفيف على المعالج.
- كل صفقة قديمة ترسم حواجها **في بلاصتها برك** (الفجوة والخطوط توقف في آخر مربّع
  الصفقة) — علاش الشارت يبقى نظيف مهما كان التاريخ طويل. الصفقة المفتوحة وحدها
  تتمدّد لليمين.
- الصفقات القديمة تتلوّن بالنتيجة: `+378 PIPS` (خضراء) ولا `-241 PIPS` (حمراء)،
  والصفقة الجارية تتكتب `running` مع نسبة الـ R.
- الدخول = **أمر Stop على مستوى السيولة المكنوس** (موش Limit): يتنفّذ كي يعدّي السعر
  المستوى راجع، وهذا اللي صار في الفيديو. كان الكنس والاسترجاع صاروا في نفس الشمعة،
  الدخول يتحسب بسعر إغلاق تلك الشمعة (لأنّ الأمر ما كانش موجود قبل).
- تقييم النتيجة يفترض ضرب الستوب قبل الهدف كي الشمعة تلمس الزوز — يعني تقييم متحفّظ.
- المؤشر **ما يفتحش صفقات** — رسم وتنبيه برك.
