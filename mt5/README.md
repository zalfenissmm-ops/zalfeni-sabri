# مؤشر MT5 — ستراتيجية الفيديو (FVG + سيولة + كسر هيكلي)

`SMC_VideoStrategy.mq5` — مؤشر MetaTrader 5 يطبّق **نفس الموديل** اللي في الفيديو:
يرسم الشروط وقت ما تتحقّق، وكي يكمّلوا الثلاثة يرسم الصفقة بنفس الشكل
(مربع أخضر للهدف + مربع أحمر للمخاطرة + خطوط Entry / SL / TP #1 / TP).

يخدم على **كل الأزواج وكل الفريمات** — ما فمّاش أي قيمة ثابتة بالنقاط،
كل شي محسوب نسبة لارتفاع الفجوة السعرية.

## الشروط الثلاثة كيما يحسبهم المؤشر

| الشرط | التطبيق في الكود |
|---|---|
| ١- فجوة سعرية (FVG) | عدم توازن على ٣ شمعات: `low[j] > high[j-2]` (صاعدة) أو `high[j] < low[j-2]` (هابطة). الفجوة تبقى صالحة حتى تسكّر شمعة تحت قاعها (أو فوق قمّتها للهابطة). |
| ٢- سيولة (LQ) | آخر قاع/قمّة مؤكّدة (fractal بنافذة `InpSwingWindow`). لازم الشمعة **تكنس** المستوى (الويك يعدّي تحتو) **و** الويك يوقف داخل الفجوة. |
| ٣- كسر هيكلي (BOS) | آخر قمّة مؤكّدة (للشراء) = **الهدف**. الدخول يتأكّد كي شمعة تسكّر راجعة فوق مستوى السيولة المكنوس خلال `InpReclaimBars` شمعات. |

**مستويات الصفقة (نفس حساب الفيديو):**

```
Entry = مستوى السيولة المكنوس (LQ)
SL    = أدنى نقطة بين قاع الفجوة وويك الكنس  −  هامش
TP    = مستوى الكسر الهيكلي (BOS)            +  هامش
TP #1 = نص المسافة بين الدخول والهدف
الهامش = InpBufferPercent % من ارتفاع الفجوة (افتراضي 25%)
```

### مطابقة مع صفقة الفيديو (XAUUSD 1H)

| | الفيديو | المؤشر بالإعدادات الافتراضية |
|---|---|---|
| Entry | 4,364.48 | 4,364.16 (مستوى السيولة) |
| SL | 4,340.29 | ≈ 4,340.75 |
| TP #1 | 4,383.88 | ≈ 4,382.95 |
| الهدف (BOS) | 4,402.36 | ≈ 4,401.75 |
| النتيجة | 378 pips | ≈ 376 pips (1.6R) |

## التركيب

1. انسخ `SMC_VideoStrategy.mq5` لـ:
   `<مجلد بيانات MT5>/MQL5/Indicators/` — من المنصّة: **File → Open Data Folder**.
2. افتح MetaEditor (F4) → افتح الملف → **Compile** (F7).
3. في MT5: **Navigator → Indicators → SMC_VideoStrategy** → سحب على الشارت.

## الإعدادات

**كشف الإعداد**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpLookbackBars` | 600 | عدد الشمعات اللي يحلّلها |
| `InpSwingWindow` | 3 | نافذة القمم/القيعان (زيدها = قمم أكبر وأقل إشارات) |
| `InpReclaimBars` | 3 | كم شمعة مسموح باش يرجع السعر فوق/تحت مستوى السيولة |
| `InpRequireCE` | false | يشترط الويك يوصل لنص الفجوة (CE) — فلتر أقوى |
| `InpAtrPeriod` | 14 | فترة الـ ATR (يتقاس بيه حجم الفجوة) |
| `InpMinFvgAtrPct` | 30 | أصغر حجم مقبول للفجوة = 30% من الـ ATR — يقتل الفجوات الصغيرة والضجيج |
| `InpAllowBuys` / `InpAllowSells` | true | تفعيل الشراء / البيع |
| `InpMinRR` | 0 | أدنى نسبة ربح/مخاطرة (مثلاً 1.5 باش يتجاهل الصفقات الضعيفة) |

**المستويات**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpBufferPercent` | 25 | هامش الستوب/الهدف كنسبة من ارتفاع الفجوة |
| `InpTP1Percent` | 50 | موقع TP #1 من المسافة للهدف |

**الشكل والرسم**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpApplyVideoTheme` | true | يبدّل ألوان الشارت لشكل الفيديو (خلفية سوداء، شموع TradingView، بلا grid). **الألوان الأصلية ترجع وحدها كي تنحّي المؤشر** |
| `InpAutoContrast` | true | كان الشارت خلفيتو بيضاء، يبدّل الباليتة تلقائيًا لألوان فاتحة تتقرا |
| `InpMaxSetups` | **1** | كم صفقة تتبقى مرسومة — 1 = آخر صفقة برك، كيما الفيديو |
| `InpTradeBoxBars` | 30 | عرض مربع الصفقة بالشمعات |
| `InpShowFvgBoxes` | true | رسم الفجوات القريبة من السعر |
| `InpMaxFvgBoxes` | **2** | عددهم الأقصى |
| `InpFvgMaxAgeBars` | 300 | يتجاهل الفجوات الأقدم من هكا |
| `InpShowLevels` | true | خطوط LQ و BOS الحالية (ما يرسمهمش كان الصفقة ديجا مفرجاهم) |
| `InpShowPanel` | false | لوحة صغيرة تفرّج حالة الشروط الثلاثة |
| `InpPipSize` | 0 (تلقائي) | حجم الـ pip لحساب النتيجة (تلقائي: 0.1 للذهب و 5 أرقام) |

**التنبيهات**

| الإعداد | الافتراضي | الوظيفة |
|---|---|---|
| `InpAlertPopup` / `InpAlertPush` | true / false | تنبيه المنصّة / إشعار على الموبايل |

## كان الشارت مازال مزحّم

- زيد في `InpMinFvgAtrPct` (مثلاً 60) → فجوات أكبر وأقلّ.
- زيد في `InpSwingWindow` (مثلاً 5) → قمم/قيعان أكبر = صفقات أقلّ وأنضف.
- حط `InpMinRR = 1.5` → يتجاهل الصفقات الضعيفة.
- حط `InpShowFvgBoxes = false` → يرسم برك الفجوة اللي عطات الصفقة.
- نقّص `InpLookbackBars` (مثلاً 300) → تاريخ أقصر.
- **مهم:** كان عندك مؤشرات أخرى على نفس الشارت (Zones / Map / …) هوما زادة يرسمو صناديق —
  نحّيهم من `Ctrl+I` باش تشوف مؤشرنا وحدو.

## ملاحظات

- المؤشر يحسب **مرّة كل شمعة مغلقة** (موش كل تيك) — خفيف على المعالج.
- الصفقات القديمة تتلوّن بالنتيجة: `+378 PIPS` (خضراء) ولا `-241 PIPS` (حمراء)،
  والصفقة الجارية تتكتب `running` مع نسبة الـ R.
- الدخول مرسوم على مستوى السيولة المكنوس: عمليًا هو **أمر Limit** على إعادة اختبار
  المستوى، كيما اترسم في الفيديو بعد ما رجع السعر فوقو.
- تقييم النتيجة يفترض ضرب الستوب قبل الهدف كي الشمعة تلمس الزوز — يعني تقييم متحفّظ.
- المؤشر **ما يفتحش صفقات** — رسم وتنبيه برك.
