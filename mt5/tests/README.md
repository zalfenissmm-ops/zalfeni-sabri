# اختبار المؤشر بدون MetaTrader

MetaEditor ما يخدمش على لينكس، أما الكود روحو ينجّم يتجرّب: `mql5_mock.h` فيه نسخة
مصغّرة من دوال MQL5 (رسم الكائنات، المصفوفات، الدوال الرياضية)، و`convert.py` يبدّل
صياغة MQL5 لـ C++ **بدون ما يمسّ المنطق** (يشيل `#property`، يبدّل `input` بمتغيّر عادي،
والمصفوفات الديناميكية بـ `MqlArray`).

```bash
./run_tests.sh
```

## شنوّة يتجرّب

**١. سيناريو الفيديو** — شموع تعيد وضعية XAUUSD متاع الفيديو (فجوة 4345/4362،
سيولة 4364.16، قمّة 4397.83، كنس لـ 4347 ثمّ ارتداد). لازم يكشف صفقة شراء وحدة
بنفس المستويات ويرسم: مربّع الفجوة + خطّ LQ + خطّ BOS + مربّع الصفقة + النتيجة.

**٢. داتا عشوائية (72,000 شمعة)** — random walk بلا اتجاه.
هذا **موش backtest**: الهدف منّو التأكّد إلّي حساب النتائج نظيف.
سوق عشوائي ما فيهش أفضلية، فالمؤشر لازم يعطي تقريبًا **0.00R** في المعدّل.
كان يعطي رقم موجب كبير → معناها فمّا خطأ في الكود (look-ahead ولا حساب غالط)،
وهذا بالضبط كيفاش تلقاو زوز أخطاء حقيقيين:

- النتائج `no fill` كانت تتحسب أرباح (لأنّ الكود كان يقارن `result > 0`)؛
- نموذج الدخول كان Limit يستنّى رجوع السعر، والصحيح Stop على المستوى كيما في الفيديو.
